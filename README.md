# 📊 Expense & Reimbursement Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Expense & Reimbursement Analysis Dashboard** created using Microsoft Power BI.

The goal of the project was to clean, transform, analyze, and visualize reimbursement data to generate useful business insights.

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning
* Data Transformation
* Data Visualization

## 🔄 Data Preparation

The dataset was transformed using Power Query.

Key data-cleaning steps included:

* Correcting spelling and punctuation errors in expense types
* Standardizing project names
* Handling missing currency values
* Creating conditional logic for missing currencies
* Converting USD and EUR amounts into INR

## 📊 Dashboard Features

The dashboard includes:

* Total reimbursement amount
* Project B reimbursement amount
* Declined request count
* Employee-wise reimbursement analysis
* Project-wise reimbursement analysis
* Employee slicer
* Project filtering
* Interactive visualizations

## 📈 Key Insights

Based on the dashboard:

* Total reimbursement: **₹650,334**
* Project B reimbursement: **₹150,803**
* Declined requests: **2**
* Highest employee reimbursement: **Siva — ₹141,461**
* Project A represents approximately **54%** of total reimbursement
